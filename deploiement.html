StepStore · Kit de déploiement
GitHub Pages + Google Sheets + WhatsApp

Ce guide explique exactement quels fichiers déployer, dans quel ordre, et comment configurer la boutique (admin, base de données Sheets et commandes WhatsApp).

1 Les fichiers à déployer sur GitHub

Le dossier dist/ généré par npm run build contient tout le livrable. Poussez ces fichiers tels quels dans votre dépôt GitHub :

stepstore/                    ← dossier du dépôt GitHub
├── index.html            ← L'APPLICATION COMPLÈTE (boutique + panier + admin)
│                              bilingue FR/AR, devise DZD, PWA intégrée
├── Code.gs               ← à coller dans Google Apps Script (base de données)
├── deploiement.html       ← ce guide (facultatif)
├── manifest.webmanifest     ← PWA : nom, couleurs, icônes
├── sw.js                    ← PWA : service worker (cache hors-ligne)
└── icons/
    └── icon-512.png         ← icône installable

2 Publier sur GitHub & GitHub Pages

  1. Créez un dépôt sur github.com (ex : stepstore).
  2. Copiez les fichiers du livrable dans le dépôt, puis :
# --- Première publication ---
git init
git add .
git commit -m "StepStore v1 — boutique + admin + WhatsApp"
git branch -M main
git remote add origin https://github.com/VOTRE-USER/stepstore.git
git push -u origin main

# --- Mise en ligne GitHub Pages ---
git checkout -b gh-pages
git push origin gh-pages
  1. Dépôt → Settings → Pages : Source = Deploy from a branch, branche gh-pages, dossier / (root).
  2. La boutique est en ligne sur : https://VOTRE-USER.github.io/stepstore/
✅ Aucune configuration serveur nécessaire : le routage est en mode hash, tout fonctionne sur un hébergement 100 % statique.

3 Base de données Google Sheets (fichier Code.gs)

  1. Créez un Google Sheet vide : docs.google.com/spreadsheets.
  2. Dans le sheet : Extensions → Apps Script, collez tout le contenu du fichier Code.gs, puis enregistrez.
  3. Déployer → Nouveau déploiement → Application Web :
    • Exécuter en tant que : Moi
    • Qui a accès : Toute personne
  4. Copiez l'URL « Web app » (elle se termine par /exec).
  5. Test rapide : ouvrez …/exec?action=bootstrap dans un navigateur — les feuilles Produits, Categories et Parametres se créent automatiquement avec des données d'exemple.
Action APIDescription

4 Configurer la boutique (admin & WhatsApp)

  1. Ouvrez la boutique, cliquez sur Admin et connectez-vous avec le mot de passe par défaut : 
    admin123
  2. Articles / Catégories : ajoutez, modifiez ou supprimez votre catalogue.
  3. Apparence → 💬 Commande WhatsApp : saisissez le numéro du vendeur au format international sans « + » (ex : 213550123456) puis « Enregistrer ». Cliquez « Envoyer un test » pour vérifier.
  4. Apparence → 🔐 Sécurité : changez le mot de passe admin.
✅ Une fois le numéro configuré, le bouton « Commander via WhatsApp » ouvre WhatsApp (wa.me) avec un message prêt : articles, tailles, couleurs, quantités, nom, téléphone, adresse et total en dinars (DZD).
⚠️ Tant qu'aucun numéro n'est configuré, le bouton de commande est désactivé et un message d'avertissement s'affiche dans le panier.

5 Notes de sécurité & évolution

Google Sheets n'est pas une base de données sécurisée : toute personne connaissant l'URL /exec peut lire les données. Pour un vrai e-commerce, migrez vers Supabase, Firebase ou une API dédiée — la couche d'accès aux données est isolée et remplaçable en un point unique du code.
