2 Publier sur GitHub & activer GitHub Pages

Deux méthodes : via l'interface web (la plus simple) ou via Git (recommandé pour les mises à jour).

Méthode A — Interface web (sans Git)

  1. Sur github.com : bouton + → New repository. Nom : stepstore, visibilité Public. Créez le dépôt.
  2. Dans le dépôt : Add file → Upload files. Renommez d'abord boutique.html en index.html, puis envoyez index.html, Code.gs et deploiement.html.
  3. Commit changes avec le message : StepStore v1 — livrable.
  4. Dépôt → Settings → Pages : Source = Deploy from a branch, branche main, dossier / (root), puis Save.
  5. Attendez 1 à 2 minutes : votre boutique est en ligne sur
    https://VOTRE-USER.github.io/stepstore/

Méthode B — Ligne de commande Git

# --- Première publication ---
git init
git add .
git commit -m "StepStore v1 — boutique + admin + WhatsApp"
git branch -M main
git remote add origin https://github.com/VOTRE-USER/stepstore.git
git push -u origin main

# --- Branche de production (alternative recommandée) ---
git checkout -b gh-pages
git push origin gh-pages

# --- Puis : Settings → Pages → branche gh-pages → dossier / (root) ---

# --- Mise à jour du site après modification ---
npm run build          # régénère dist/index.html
git add dist/index.html
git commit -m "Mise à jour boutique"
git push

3 Base de données Google Sheets (fichier Code.gs)

  1. Créez un Google Sheet vide : docs.google.com/spreadsheets.
  2. Dans le sheet : Extensions → Apps Script. Effacez le contenu par défaut et collez tout le contenu du fichier Code.gs. Enregistrez (icône 💾).
  3. Déployer → Nouveau déploiement → Application Web :
    • Description : StepStore API
    • Exécuter en tant que : Moi
    • Qui a accès : Toute personne
  4. Déployer puis autorisez les permissions demandées (avis « application non vérifiée » → Paramètres avancés → Autoriser).
  5. Copiez l'URL « Web app » (elle se termine par /exec).
  6. Test : ouvrez dans un navigateur …/exec?action=bootstrap — les feuilles Produits, Categories et Parametres se créent automatiquement avec des données d'exemple.
Action APIDescription
pingTest de connexion (renvoie la version)
all / getProducts / getCategories / getSettingsLecture des données
saveProduct / deleteProductÉcriture des articles
saveCategory / deleteCategoryÉcriture des catégories
saveSettings / syncAll / bootstrapRéglages + synchronisation complète

4 Configurer la boutique (admin + Sheets + WhatsApp)

  1. Ouvrez boutique.html (double-clic), cliquez sur Admin (menu du haut) et connectez-vous : 
    Mot de passe par défaut : admin123
  2. Relier Google Sheets : ouvrez boutique.html dans un éditeur de texte (Bloc-notes), cherchez var SHEETS_URL = ""; et collez votre URL /exec entre les guillemets. Au démarrage, la boutique charge les données de Sheets.
  3. Articles : ajoutez / modifiez / supprimez les produits (nom, marque, prix en DA, images par URL ou fichier, couleurs, tailles, stock, popularité).
  4. Catégories : créez vos catégories (Running, Lifestyle…) avec image et emoji.
  5. Apparence → Couleurs : changez la couleur principale, le fond et le texte — appliqués instantanément.
  6. Apparence → Textes : modifiez les titres et messages en français ET en arabe (section « 🌐 Textes en arabe »).
  7. Apparence → Logo & images : téléversez votre logo et vos images.
  8. Apparence → 💬 Commande WhatsApp : saisissez le numéro du vendeur au format international sans « + » (ex : 213550123456) puis « Enregistrer ». Cliquez « Envoyer un test » pour vérifier.
  9. Apparence → 🔐 Sécurité : changez le mot de passe admin.
✅ Une fois le numéro WhatsApp configuré, le bouton « Commander via WhatsApp » ouvre WhatsApp (wa.me) avec un message prêt : articles, tailles, couleurs, quantités, nom, téléphone, adresse et total en dinars (DZD), dans la langue du client (FR ou AR).

5 Dépannage

ProblèmeSolution
Écran blanc au chargementUn message d'erreur s'affiche automatiquement si l'application ne démarre pas. Rechargez la page ; si le problème persiste, videz le cache du navigateur ou testez dans une fenêtre privée. Vérifiez aussi que le fichier index.html est complet (recopié intégralement depuis dist/).
Le produit 3D ne s'affiche pasLa vue 3D nécessite une connexion Internet (le modèle est chargé depuis un CDN public) et WebGL. Sans Internet ou sans WebGL, la fiche produit bascule automatiquement sur les photos — c'est normal.
Bouton « Commander » désactivéLe numéro WhatsApp n'est pas encore configuré : Admin → Apparence → 💬 Commande WhatsApp.
Les images de démonstration ne s'affichent pasElles viennent de Pexels (CDN) : une connexion Internet est requise. Remplacez-les par vos propres images dans Admin → Articles.
Les modifications ne sont pas conservéesElles sont stockées dans le navigateur (localStorage). Pour une base centralisée, utilisez Google Sheets (étape 3) puis rechargez la boutique en mode connecté.
Erreur CORS avec Google SheetsVérifiez que l'API est déployée en « Application Web » (et non API exécutable), avec accès « Toute personne », et utilisez bien l'URL qui se termine par /exec.

6 Sécurité & évolution

Google Sheets n'est pas une base de données sécurisée : toute personne connaissant l'URL /exec peut lire les données. Pour un vrai e-commerce, migrez vers Supabase, Firebase ou une API dédiée — la couche d'accès aux données est isolée et remplaçable en un point unique du code. Le paiement est une redirection WhatsApp : aucun encaissement en ligne.
