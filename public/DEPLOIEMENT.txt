====================================================================
STEPSTORE — MODE DÉPLOIEMENT (livrable autonome)
====================================================================

NOUVEAU LIVRABLE : la boutique est maintenant un fichier HTML
AUTONOME qui fonctionne en double-cliquant dessus, sans installation,
sans build et sans dépendance.

--------------------------------------------------------------------
1. FICHIERS DU LIVRABLE
--------------------------------------------------------------------

  boutique.html     <- L'APPLICATION COMPLÈTE (HTML + CSS + JS intégrés)
                       Bilingue FR/AR (RTL) · Devise DZD · Vue 3D du
                       produit · Commande par redirection WhatsApp ·
                       Panneau d'administration complet.
                       OUVRIR : double-clic sur le fichier.

  Code.gs           <- Code JavaScript de configuration Google Sheets.
                       À coller dans Extensions > Apps Script de votre
                       Google Sheet (c'est la base de données).

  deploiement.html  <- Guide de déploiement détaillé (facultatif).

  DEPLOIEMENT.txt   <- Ce guide en texte brut.

--------------------------------------------------------------------
2. PUBLIER SUR GITHUB PAGES
--------------------------------------------------------------------

  1. Créez un dépôt sur github.com (ex : stepstore).
  2. Renommez boutique.html en index.html  (obligatoire pour que
     GitHub Pages l'affiche comme page d'accueil).
  3. Envoyez dans le dépôt : index.html, Code.gs, deploiement.html,
     DEPLOIEMENT.txt.
  4. Dépôt -> Settings -> Pages :
       Source = Deploy from a branch
       Branche = main
       Dossier = / (root)
     puis Save.
  5. Attendez 1 à 2 minutes : la boutique est en ligne sur
     https://VOTRE-USER.github.io/stepstore/

  EN LIGNE DE COMMANDE (optionnel) :

    git init
    git add .
    git commit -m "StepStore — boutique autonome"
    git branch -M main
    git remote add origin https://github.com/VOTRE-USER/stepstore.git
    git push -u origin main

--------------------------------------------------------------------
3. CONFIGURER GOOGLE SHEETS (fichier Code.gs)
--------------------------------------------------------------------

  1. Créez un Google Sheet vide : docs.google.com/spreadsheets
  2. Extensions -> Apps Script : collez TOUT le contenu du fichier
     Code.gs, puis enregistrez.
  3. Déployer -> Nouveau déploiement -> Application Web :
       Exécuter en tant que : Moi
       Qui a accès : Toute personne
  4. Copiez l'URL « Web app » (elle se termine par /exec).
  5. Test : ouvrez .../exec?action=bootstrap dans un navigateur.
     Les feuilles Produits, Categories et Parametres se créent
     automatiquement.

  POUR RELIER LA BOUTIQUE AUX SHEETS :
    Ouvrez boutique.html dans un éditeur de texte.
    Cherchez la ligne :  var SHEETS_URL = "";
    Collez votre URL entre les guillemets :
    var SHEETS_URL = "https://script.google.com/macros/s/XXXX/exec";
    Enregistrez. Au démarrage, la boutique charge automatiquement
    les données de Sheets.

    Actions disponibles : ping, all, getProducts, getCategories,
    getSettings, saveProduct, deleteProduct, saveCategory,
    deleteCategory, saveSettings, syncAll, bootstrap.

    Envoi manuel depuis la console du navigateur (F12) :
      window.stepstore.pullFromSheets()
      window.stepstore.pushToSheets()

--------------------------------------------------------------------
4. CONFIGURER LA BOUTIQUE (ADMIN)
--------------------------------------------------------------------

  1. Ouvrez boutique.html, cliquez sur Admin (menu du haut) :
     mot de passe par défaut : admin123
  2. Articles : ajoutez, modifiez ou supprimez les produits
     (nom, marque, prix en DA, images, couleurs, tailles, stock).
  3. Catégories : créez vos catégories (nom, emoji, image).
  4. Apparence -> Couleurs : couleurs de l'interface (appliquées
     instantanément).
  5. Apparence -> Textes : textes en FRANÇAIS et en ARABE
     (section « 🌐 Textes en arabe »).
  6. Apparence -> Logo & images : logo, image du hero, promo.
  7. Apparence -> Commande WhatsApp : numéro du vendeur au format
     international sans « + » (ex : 213550123456) puis Enregistrer,
     puis « Envoyer un test ».
  8. Apparence -> Sécurité : changez le mot de passe admin.

  Une fois le numéro WhatsApp configuré, le bouton
  « Commander via WhatsApp » ouvre wa.me avec un message prêt :
  articles, tailles, couleurs, quantités, nom, téléphone, adresse
  et total en dinars (DZD), en français ou en arabe.

--------------------------------------------------------------------
5. DÉPANNAGE
--------------------------------------------------------------------

  Page blanche         -> Vérifiez que le fichier est complet et
                          ouvert dans un navigateur récent
                          (Chrome, Firefox, Edge). Le JavaScript
                          doit être activé.

  Produit 3D absent    -> La vue 3D exige Internet (modèle chargé
                          depuis un CDN) et WebGL. Sinon, la fiche
                          bascule automatiquement sur les photos.

  Bouton « Commander » -> Numéro WhatsApp non configuré :
  désactivé               Admin -> Apparence -> Commande WhatsApp.

  Images manquantes    -> Les images de démonstration viennent d'un
                          CDN (Internet requis). Remplacez-les par
                          vos images dans Admin -> Articles.

  Modifications        -> Elles sont stockées dans le navigateur
  non conservées          (localStorage). Elles restent sur la même
                          machine / le même navigateur. Pour une
                          base centralisée : Google Sheets (étape 3).

--------------------------------------------------------------------
6. SÉCURITÉ
--------------------------------------------------------------------

  Google Sheets n'est pas une base sécurisée : toute personne
  connaissant l'URL /exec peut lire les données. Pour un vrai
  e-commerce, migrez vers Supabase, Firebase ou une API dédiée.
  Le paiement est une redirection WhatsApp (aucun encaissement
  en ligne).
